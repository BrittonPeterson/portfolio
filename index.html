Software for decks, data, and the small tools in between.

I’m Britton Peterson. Most of what I build looks at Magic: The Gathering from the data side: matchup tables, deck comparison, and a way to ask questions about the metagame. This page is a short record of that work, plus coursework.

GitHub Email

01 About

I write Python and JavaScript, and I like projects that turn a messy public dataset into something you can actually read. A lot of that has been Endstep metagame numbers, Commander decklists, and 60-card constructed lists.

The work below is on GitHub. Descriptions stay close to what each repository actually does.

02 Selected work

  1. 01 Python · JavaScript

    Endstep Meta Table

    A local matchup matrix for Endstep’s public metagame data. A Python scraper takes the top Pauper decks and their win rates, and a Node page shows the snapshot as a color-coded table that can refresh about once a day.

  2. 02 TypeScript · React · Python

    MTG Analysis Tool

    A query front end over metagame data. The React app talks to a FastAPI backend that handles matchup questions, win-rate lookups, and top-deck queries.

  3. 03 Python

    Compare Decks

    Python programs for comparing Commander (EDH) decklists so two lists can be lined up instead of read side by side by hand.

  4. 04 Python

    60-Card Deck Analysis

    A Python tool for looking at 60-card constructed decks, with deck lists kept alongside the analysis script.

  5. 05 Python · coursework

    CIS 121 To-Do List

    A command-line to-do list from CIS 121. Tasks can be added, marked complete, removed, and printed from a small pair of Python classes.
