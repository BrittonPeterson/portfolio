# Britton Peterson — Portfolio

Static class portfolio, ready for GitHub Pages.

Live site (after Pages is enabled): [https://brittonpeterson.github.io/portfolio/](https://brittonpeterson.github.io/portfolio/)

## What’s on the page

- Short intro and about section
- Experience, including the Thomson Reuters contract
- Selected projects
- Skills from the resume
- Phone, email, and GitHub contact links

## Publish on GitHub Pages

1. Push this folder to a public repository named `portfolio` on the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait a minute, then open the Pages URL GitHub shows.

The site uses relative paths, so it also works if you rename the repository, as long as `index.html` stays at the root of the published branch.
